## Monitoring Eurasian lynx demography with systematic and opportunistic data
**Francesco Bini, Ira Topličanec, Magda Sindičić & Tomislav Gomerčić**

This repository contains the R code and data associated with:  Bini, F., Topličanec, I., Sindičić, M., & Gomerčić, T. (2026). Integrating systematic and opportunistic camera trap data to monitor Eurasian lynx demography. *Journal of Zoology, 330*(1), 50–61. https://doi.org/10.1111/jzo.70144

The file names indicate the order in which to run the scripts and the dataset used by each.
